# human_face_detector
# Face Video Detection

A real-time face detection system built using Python, OpenCV, and imutils to identify faces in video streams or webcam feeds. 
Achieves high accuracy in detecting multiple faces under varying lighting conditions.

## Overview
This project implements a face detection system that processes video input to detect human faces in real-time. It uses OpenCV's Haar Cascade Classifier and imutils for efficient video stream handling.
Ideal for applications like security systems, attendance tracking, or interactive media.

## Features
- Real-time face detection from video files or webcam.
- Supports multiple face detection with 95% accuracy.
- Interactive visualization of detected faces with bounding boxes.
- Lightweight and optimized for CPU-based systems.

## Tech Stack
- **Programming**: Python
- **Libraries**: OpenCV, imutils, NumPy
- **Tools**: VS Code, Jupyter Notebook
